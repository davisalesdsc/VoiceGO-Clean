Instalado!

  1. Abra o seu programa e peça para procurar plugins de novo (REAPER: Options › Preferences › Plug-ins › VST › Re-scan. Logic: basta reabrir).
  2. Coloque VoiceGO Clean na trilha da voz.
  3. Gire Ambience e Voice Reverb para a esquerda para limpar; 0 dB = original. S = ouvir só aquela parte, M = remover. Duplo clique volta o knob para 0 dB.

Para desinstalar: abra a pasta /Library/Application Support/VoiceGO Clean e dê dois cliques em “Desinstalar VoiceGO Clean”.
